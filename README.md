# Vynora Campus+ — Production College Community & Productivity Platform

A full-stack, secure campus operations and community platform tailored for universities and colleges. Built with React (TypeScript), Node.js, Express, Socket.IO, and MongoDB Atlas.

---

## 🌟 Key Modules & Capabilities

1. **Campus Services & Free Room Finder**
   - Interactive study room finder categorized by campus blocks:
     - Block 1 (CSE & IT)
     - Block 2 (ECE & EEE)
     - Block 3 (Sciences & Humanities)
     - Central Library
     - Design Studio & Student Activity Center (SAC)
     - Mechanical & Robotics Block
   - Filter by real-time room availability (e.g. 90+ min free study slots).
   - Amenity checklists (AC, Projectors, Wi-Fi, Whiteboards) and step-by-step campus directions.

2. **Academic Resources & Question Paper Repository**
   - Upload, preview, and download study materials:
     - Mid-term Exam Papers
     - End-term Exam Papers
     - Lecture Notes
     - Lab Manuals
     - Handwritten Problem Solutions & Photo Scans
   - Direct high-resolution photo viewer modal and document download counters.

3. **College Clubs & Guilds**
   - Official university-approved student bodies and societies.
   - Admin-governed club creation (removes unauthorized club creation).
   - "Interested / Join Club" subscription model.
   - Targeted notification isolation: Students only receive announcements for clubs they have actively joined.

4. **Timetable Integration**
   - Live synchronization with SRUX Timetable engine (`https://www.srux.in/timetable`).
   - Dynamic schedule rendering by department, batch, and academic year.

5. **Community, Projects & Network**
   - Peer networking, student directory, project showcase, and student marketplace.
   - Real-time messaging powered by Socket.IO with dynamic unread indicators.

6. **Role-Based Access Control (RBAC)**
   - Dedicated Admin portal (`/admin/login`) with separate authentication and audit logging.
   - Protected metrics and content moderation.

```
vynoracampus+/
├── src/                    # Frontend React + TypeScript application
│   ├── features/           # Feature slices (clubs, timetable, admin, products)

│   └── index.css           # Design tokens, typography, and styles
├── server/                 # Express REST & WebSocket API backend

│   └── index.mjs           # Server bootstrap and Socket.IO configuration
├── dist/                   # Production build artifact (generated by vite)
└── package.json            # Project dependencies and npm scripts
```

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+
- MongoDB Atlas cluster or local MongoDB instance

### 1. Clone & Install
```bash
git clone https://github.com/KARTHIKKAR5/VYNORACAMPUS-.git
cd VYNORACAMPUS-
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure your MongoDB Atlas connection string is configured:
```env
PORT=8787
CLIENT_URL=http://localhost:5173
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/vynora?retryWrites=true&w=majority
JWT_SECRET=your_jwt_secret_key
SESSION_SECRET=your_session_secret_key
ADMIN_BOOTSTRAP_KEY=vynora_admin_init_2026
```

### 3. Run Locally
Start the backend server:
```bash
node server/index.mjs
```

Start the frontend Vite server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🚢 Deployment Guide

### Frontend (Vercel / Netlify)
- **Framework Preset**: Vite
- **Root Directory**: `./`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Environment Variables**:
  - `VITE_API_URL`: Your deployed backend API URL (e.g., `https://api.vynoracampus.com/api/v1`)

### Backend (Render / Railway / Fly.io)
- **Build Command**: `npm install`
- **Start Command**: `node server/index.mjs`
- **Environment Variables**:
  - `NODE_ENV=production`
  - `PORT=8787` (or system-assigned `$PORT`)
  - `CLIENT_URL=https://your-frontend.vercel.app`
  - `MONGODB_URI=your_mongodb_atlas_uri`
  - `JWT_SECRET=your_production_jwt_secret`
